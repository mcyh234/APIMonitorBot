# AI 消息推送账号推荐

账号库核对日期：2026-10-21。内置 69 个 X 账号，涵盖模型公司、产品、技术负责人和创始人。WebUI 的「监控管理 → AI 消息监听」可搜索、分类选择或添加自定义用户名。

## 选择建议

- **推荐组合**：优先关注模型、API、产品发布与技术一线消息；包含原有 Tibo。
- **全部账号**：也包括老板与个人观点、公司综合动态、Grok 公开互动等，消息量较大。
- **按类选择**：公司与产品适合追踪正式发布；负责人适合跟进开发进展；创始人适合了解方向和观点。

个人账号不保证只发布 AI 内容。账号归属不表示其全部帖子都是正式公告；没有可核验账号的负责人不虚构账号。

所有账号均受不可关闭的严格内容过滤：政治和其他高风险内容、非 AI 个人观点会跳过。需在 WebUI「群聊情报 → 分析模型」配置审核模型，无需开启群聊采集；没有模型或审核不可用时暂停投递。订阅老板号不会豁免内容审核。

## 账号核对与维护

以官网、官方代码仓库和账号自身资料作为归属核对依据。例如：

- [DeepSeek 官网](https://www.deepseek.com)、[Qwen 官方组织](https://github.com/QwenLM)、[Kimi 官方仓库](https://github.com/MoonshotAI/Kimi-K2)。
- [MiniMax 官方组织](https://github.com/MiniMax-AI) 当前指向 `@MiniMax_AI`；其部分旧网站页面仍指向双下划线旧号，监听采用官方组织所列账号。
- [Thinking Machines 官网](https://thinkingmachines.ai) 指向 `@thinkymachines`。
- [Groq 官网](https://groq.com) 指向 `@GroqLLC`，[Cerebras 官网](https://www.cerebras.ai) 指向 `@Cerebras`。
- [Black Forest Labs 官网](https://blackforestlabs.ai) 指向 `@bfl_ai`，[Suno 官网](https://suno.com) 指向 `@suno`。
- [Windsurf 官网](https://windsurf.com) 当前指向 Cognition；避免订阅旧账号后一直等不到产品更新。
- 2026-10-21：[x.ai 官网](https://x.ai/) 社交入口当前指向 `@SpaceXSI`；[微软 Copilot 官方博客](https://www.microsoft.com/en-us/copilot/blog/) 的社交入口指向 `@MSFTCopilot`，微软[官方社区文章](https://techcommunity.microsoft.com/blog/microsoft_365blog/your-guide-to-the-microsoft-365-community-conference/4505384) 也列出该账号。旧 `@xai`、`@Copilot` RSS 实测持续返回 500 / 404，因此修正内置订阅入口。此记录只证明官方入口与当次抓取结果，不凭这些 HTTP 错误推断 X 账号是否已注销。

本次升级启动时执行一次订阅修正：**仅将已有订阅中的 `xai` 替换为 `spacexsi`、`copilot` 替换为 `msftcopilot`**，去重后保存，保持原监听开关、通知对象、间隔和其他账号进度。未订阅这两个入口的安装不会自动增加它们；旧 Tibo-only 配置继续保持 Tibo-only。新增官号首次只建立基线，不继承旧用户名的游标、已处理 ID 或待发送内容；旧入口的总结素材按移除订阅规则清理，活动总结失效。已独立订阅新官号时保留其已有进度。完成标记与设置更新同事务保存；之后管理员显式重新添加旧用户名不会在每次启动时再次被改写。

只读抓取核验：新账号均可返回真实时间线。FxTwitter 的 `SpaceXSI` 路径一次返回 18 条；标准监听诊断的 `spacexsi` 路径本次从 Netbub 返回 17 条，其他来源出现超时或 530；`msftcopilot` 本次从 FxTwitter 返回 59 条、Netbub 返回 20 条。不同来源覆盖量仍不一致，不能承诺完整或实时抓取。`/newswatch logs @xai`、`@copilot` 在旧入口已被替换时会提示并查看对应新账号。

预设账号不等于所有来源始终可抓取。RSS 可能限流、缓存、只保留少量帖子或暂时没有原创内容，WebUI 会分别显示状态。当前使用多源合并与限流退避，详情见 [RSS 来源维护](ai-news-sources.md)。账号更名后可在 WebUI 移除旧用户名、添加新用户名；新账号首次只建立基线。

## 使用

```text
/newswatch all
/newswatch G123456789&P1122334455
/newswatch accounts
/newswatch remove @grok
/newswatch add @another_account
/newswatch status
```

修改账号不会自动打开处于关闭状态的监听；配置通知对象会启用。旧 `/tibowatch` 操作同一份设置。所有配置命令均仅限管理员，并遵守各自的命令开关。
